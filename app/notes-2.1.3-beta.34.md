# Superagent 2.1.3-beta.34

**Edit Markdown as the page.** Markdown files now open in a WYSIWYG editor: real headings, lists and tables you type straight into, no `**` or `|` marks. The file stays plain Markdown, and a save changes only what you edited. Choose View, Edit or Source at the top of the file; Source is the plain-text editor, for when you want the raw Markdown. Saving by itself, live agent edits and the choice when both of you changed the file all work as before.

**Tables in Source are easier to read.** Each row is its own band, so a long row that wraps still reads as one row.
