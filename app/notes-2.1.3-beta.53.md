# Superagent 2.1.3-beta.53

**Conductor: smarter session titles.** Main titles each session in three to six words naming the work, and puts the tracker id in front when you name one ("WD-284 Fix header wrap"), instead of cutting the title from your message.

**Tested.** On Claude, Codex and Antigravity: in Auto a clear task starts a titled session; in Confirm Main asks first and starts it on a yes. In a real git project each session gets its own worktree and branch, closing with unmerged commits asks first and merging lands them on main, and each session has its own browser. Approve and Deny work from a session's row and from the card in Main.
