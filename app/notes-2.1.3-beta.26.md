# Superagent 2.1.3-beta.26

**Antigravity chats list their models.** An Antigravity chat's Model menu used to offer only Default, because the list was asked for with too little time to answer. It is now fetched up front, so every Antigravity model shows, once each with its efforts beside it.

**Your phone can send its freeze reports to the Mac.** The iPhone app (next TestFlight build) writes down every freeze and crash: how long it lasted, how big the open chat was, and where it got stuck. It hands them to the Mac when it connects, which keeps them so they can be looked at. They contain no chat text.
