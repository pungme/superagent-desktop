# Superagent 2.1.0-beta.8

**Splits are easier to recognise.** Each sidebar row has a larger layout thumbnail with the projects' icons, the conversation names underneath, and a status dot when a chat is working or needs you.

**iPhone conversations can catch up past a broken emoji.** A tool summary cut halfway through an emoji could stop the phone reading that event and every newer message. The Mac now repairs malformed Unicode before sending it, including in previously saved conversations. No iOS update is needed for this fix.
