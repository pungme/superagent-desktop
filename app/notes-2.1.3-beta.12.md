# Superagent 2.1.3-beta.12

**Duplicate a chat.** Right-click a chat (in Pinned too) and choose Duplicate chat: a new chat in the same project, on the same agent and model, with the whole conversation, named "… (copy)". A copy of a pinned chat is pinned right below the original. The copy's agent has no memory of the original session, so its first message carries a recap of the conversation so far. Like "+ New chat", it gets its own branch of the project on its first message. The iPhone app's next update has Duplicate in its hold menus too.
