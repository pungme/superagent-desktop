# Superagent 1.9.1-beta.7

- Pinned rows now show their branch (e.g. "⎇ main") next to the project name.
- A pinned root chat with its own custom title now shows that title instead of always showing just the project name — the project name and branch move to the subtitle, and renaming works again once it has a real title.
- Fixed the tree's own pinned-chat marker, which still used the old illegible character.
