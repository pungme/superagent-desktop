# Superagent 1.9.1-beta.8

- The pin icon is now a real thumbtack, matching iOS — the old circle-and-stem shape is gone.
- Token usage is visible in chat: a per-turn badge on each reply, a running total for the whole conversation next to the Memory gauge, and a live count while a turn is in progress.
- You can now unpin a chat straight from the Pinned section (right-click), not just from the project tree.
