# Superagent 2.1.3-beta.25

**Screenshots in Chats.** The "Screenshot just taken" strip (Attach, Attach & delete), pasting an image, ⌘⇧A / ⌘⇧D and the snip tool now work in chats on the Chats page and in the Computer, not only in a project's chats.

**Smoother switching between agents.** When a chat moves from Claude to Codex or Antigravity because an account ran out:
- a chat running without a window (from the phone, Today or a loop) no longer hands the new agent the old agent's model;
- the recap the new agent gets no longer labels the earlier replies with its own name, so it doesn't mistake another agent's words for its own.
