# Superagent 1.9.2-beta.26

- **See how much of each account is used.** Settings → Agents → Accounts now shows a meter for each account's 5-hour and weekly allowance, with when it resets. Claude and Codex accounts; a Claude account added by token may only show its numbers after a chat has run on it.
- **Apple Mail.** Connect Mail in Settings → Connections (or when you first set up) and the agent can search and read your mail and save drafts. It never sends: a draft waits in Mail for you. macOS asks for permission the first time.
- **The intro, for everyone.** The short film that used to play only on a brand-new install now plays once for people already using Superagent too. It opens on "Hello. Welcome home." Skip ends it, and Settings → About has **Show the intro again**.
