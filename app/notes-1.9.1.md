# Superagent 1.9.1

**Your projects, at a glance**

- Every project shows what it is: a website's favicon, an app's own icon (found even inside a folder of several repos), or a glyph for a screenplay, design or music folder. Right-click to pick your own.
- One Projects section: open tabs first, then projects, with a globe button for a new tab and a folder button to add a project. Projects no longer need a group.
- A folder of several repos folds them from a caret on its own row. A repo that's still cloning says "cloning…".
- Pin conversations to the top, then drag them into the order you want. The phone follows the same order.
- `⌘K` searches projects, chats and commands, with each project's icon. `⌘J` focuses the composer and `⌘.` stops the agent.

**The agent and its browser**

- The agent keeps a browser tab of its own, so a tab you open to look something up isn't taken over.
- To check a page on a phone, the agent switches the pane to a real mobile viewport (390×844).
- A chat's browser can hold several tabs, and the agent can open, switch and close them.
- The model picker lists the models your installed Claude Code offers (Opus 5.5 and Fable 5.1 today), so new models appear without an app update. The agent picker shows the real Claude and Codex logos.

**In the conversation**

- Pictures a tool produces, and screenshots the agent puts in its reply, show inline as previews. Click for full size.
- Token usage per reply and for the whole conversation, counting up live while a turn runs.
- Timestamps group like iMessage, and sending a message scrolls you to the bottom.
- Permission asks appear in the chat that's asking, instead of a window-wide dialog.

**Faster, and it cleans up after itself**

- Much lower CPU when idle: the pulsing status dots no longer repaint the window every frame.
- Stop really stops the build or dev server the agent started, and quitting Superagent stops every agent and routine run it started.
- Typing stays responsive with many sessions running.

**On your phone** (update the iPhone app too)

- Switch between paired Macs from the title at the top.
- The same sidebar as the Mac: project icons, the repos caret, pins in your order, and search results with project icons.
- Pictures in replies open full screen, and "send when done" is held on the Mac, so it still goes out if you close the app.
