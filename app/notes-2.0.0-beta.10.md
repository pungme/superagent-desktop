# Superagent 2.0.0-beta.10

**Download a picture right where it is.** Hover any picture in a conversation, yours or the agent's, and a button in its corner saves it to Downloads without opening it.

**Computer use**

- **Only your Mac can say yes.** A request to let an agent use the Mac can be refused from a paired phone, but allowed only at the Mac, by someone who can see the screen and reach ⌥Esc.
- **It asks before an agent writes a script that could drive the Mac.** A file with code that posts mouse or keyboard events, captures the screen or changes privacy permissions is shown to you first, with its name.
- **The safety hooks are checked every time.** If they have been edited away they are put back before computer use is allowed, and if they cannot be, computer use is paused.
