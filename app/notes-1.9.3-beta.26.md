# Superagent 1.9.3-beta.26

- **Copy on a reply says "Copied".** It did its work with no sign at all, which read as a button that had done nothing.
- **A narrow chat's settings are one line.** Memory, Compact and the token count have moved into the list the line opens, instead of wrapping into two more rows under the message box. The line still says when memory is running short.
- **A gap between accounts in the usage list.** The account the chat is on and the one under the pointer no longer run into one block.
