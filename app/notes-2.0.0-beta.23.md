# Superagent 2.0.0-beta.23

**Computer use, one step at a time.**

- **Ask before each step** (Settings → Computer use, off unless you turn it on). Every click, keystroke and piece of typing is put to you first, in words ("Click “Save”", "Press cmd+s"), and happens only if you allow it. Looking, scrolling and moving the pointer are not asked about. A no stops the agent rather than sending it another way round.
