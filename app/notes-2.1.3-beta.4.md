# Superagent 2.1.3-beta.4

**A calmer floating chat in Browser first.**

- **One card.** The open chat is a single panel of its own, so it reads as on top of the page and no longer mixes into it: answers as plain text, your messages as small dark pills, the message box inside. It grows out of the icon.
- **The last exchange first.** It opens on your last message and what followed; "N earlier" (or scrolling up) brings the rest.
- **The page moves over.** While the chat is open the page slides left to make room, so the chat covers nothing; it slides back when you put the chat away.
- **Resize it.** Drag the card's left edge to make it wider or narrower; the page takes what is left, and the width is remembered.
- **Icons in the whole chat.** "Put beside the page" and "Hide" are two small icons, with the words in their tooltips.

**Save for later.** Writing a prompt and want to start another first? Press ⌘S in the message box (or the bookmark button that appears while you type): it is set aside for that chat and the box is cleared. "1 saved" above the box brings it back (whatever is in the box then is set aside in its place), sends it as it is, or throws it away. ⌘K lists every chat's saved prompts.
