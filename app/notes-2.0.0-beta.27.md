# Superagent 2.0.0-beta.27

**The dot works with the window closed.**

- **Close the window; ask anyway.** With Superagent's window closed, "Open in Superagent" on the dot did nothing, and asking it for a project opened a window on the wrong place. Both open a window on what you asked for now.
- **The dot's answer arrives a word at a time,** as replies in the chat do.
- **A reply never shows half a word.** Text that arrived cut mid-word showed the half ("the pro", then "the problem"). An unfinished word waits for the rest of itself.
