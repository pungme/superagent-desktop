# Superagent 2.0.0-beta.50

**The menu bar shows what is working, and a screenshot attaches from the keyboard.**

- **The menu bar menu lists your chats.** The ones working now, marked ●, then the five you used last, each with its project. Pick one and Superagent opens it, even with the window closed.
- **⌘⇧A attaches a screenshot you just took, ⌘⇧D attaches it and moves the file to the Trash.** The buttons show their shortcut.
- **A message waiting to send shows its pictures.** The "sends when done" line had only the text, so an attached image looked lost; its thumbnails sit beside the text now, and a click opens one.
- **Starting a loop no longer says so twice.** The "🔁 Looping: …" line sat right above the first round, which already shows the prompt, as does the loop bar. Stop, pause and the usage line still answer in the chat.
