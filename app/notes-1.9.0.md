# Superagent 1.9.0

- Long conversations stay fast by rendering only the visible part of the transcript.
- Adding a code folder opens exactly one usable root conversation without a duplicate nested chat.
- Project and branch navigation now consistently opens the requested chat from every app screen.
- Agents can reliably tap and swipe portrait and landscape iPhone and iPad simulators.
- Claude Code's **Default** model falls back from Fable to Opus when Fable is unavailable or exhausted.
- Images sent from the iOS share sheet appear immediately in the live desktop conversation.
- Update checks recover from a stuck Electron network service, and **Restart to update** now relaunches the app after installation.
