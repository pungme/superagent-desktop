# Superagent 2.0.0-beta.54

**The menu bar icon is there, and a restart reopens where you were.**

- **A menu bar icon you can see.** The icon at the top of the screen was never drawn: it was an empty image, so there was only an invisible gap that opened the menu. It is now the Superagent mark, tinted by macOS for a light or dark menu bar. Its middle square breathes while a chat is working, a dot appears in its corner when a chat is waiting on you, and it fades when your phone cannot reach this Mac.
- **Back to the conversation you were reading.** After an update and restart, each project opened on its newest chat instead of the one you had on screen. It now opens the one you were reading, and Chats or Computer if that is where you were.
