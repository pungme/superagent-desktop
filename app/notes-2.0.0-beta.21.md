# Superagent 2.0.0-beta.21

**Your name for a chat stays your name.**

- **A chat you named is not renamed.** Naming a chat before saying anything in it, the first message put its own words over your name, and the agent's summary replaced those after the turn. Neither touches a chat that already has a name now, wherever it was given: the window, the phone or the dot.
- **A pinned chat from Chats shows its name.** Its row under Pinned was blank. It goes by the chat's own name, opens where Chats does, and can be renamed there with a double click.
- **A picture in a folder with a space in its name is shown.** A reply pointing at a picture under "Application Support", say, showed the address as text instead of the picture.
- **Computer use can be shown only the apps you allowed** (Settings → Computer use, off unless you turn it on). In an agent's screenshots every other app's window, notifications and the desktop are covered in grey, and it is told which apps are covered so it can ask for one.
