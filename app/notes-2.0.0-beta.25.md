# Superagent 2.0.0-beta.25

**Two doors closed on computer use.**

- **The app's own program can no longer be borrowed.** It could be started as a plain script runner, or with a debugger attached, and whatever ran that way was Superagent to macOS, with its permission to see the screen and act. Those ways of starting it are switched off in the app itself.
- **Codex in Full mode is not given the Mac.** There Codex runs its commands without Superagent seeing them, and the safeguards for using the Mac depend on seeing them. Switch the conversation to Ask mode to use the Mac with Codex.
