# Superagent 2.1.3-beta.65

**Start Conductor in the app's own window.** Right-click a project → Start Conductor… now opens Superagent's own modal instead of a system alert: Start clean, or Connect the existing chats. It then takes you straight to the Conductor view.

**Tested.** e2e: the project's right-click menu, the modal, and landing in the Conductor view with the project listed under Conductor in the sidebar.
