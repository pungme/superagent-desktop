# Superagent 2.0.0-beta.58

**Fable's own allowance in the usage list.**

- **Weekly Fable.** Each Claude account shows how much of its Fable week is used, with when it starts over, beside the 5-hour and weekly bars.
- **Not counted as the account being full.** When Fable runs out the chat carries on with the next model down, so the sidebar's figure stays on the account's own allowance.

**A message that woke a sleeping chat no longer arrives twice.** If something finished while the chat slept, its silent turn was mistaken for an empty answer, and your message was sent again.

**Long thinking can be shown in full.** A thinking block too tall for its box gets "Show all", and the next one opens the way you left the last. While it is being written, the box follows the newest line.
