# Superagent 2.1.3-beta.11

**Account switching is automatic.** When an account runs out of allowance, the chat now moves to another account that still has some and sends the message that hit the limit again, with a line in the chat saying so ("Account A is out of allowance, continuing on Account B"), instead of stopping to ask. If every account is used up it tells you.

This is the default for everyone, including setups that only had "Ask" because it used to be the default. If you prefer to be asked, pick Ask in Settings → Agents → Switch accounts and it stays.
