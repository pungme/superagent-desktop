# Superagent 2.0.0-beta.31

**Setting up now asks how it should behave.**

- **A new step while setting up: "How should it behave?"** After the tour and before the connections, four decisions that used to be defaults found later in Settings: what happens when an account runs out (Ask, or switch automatically), whether agents keep working with the lid closed (and the battery level under which the Mac is let sleep), the dot, and computer use. Each is the same switch Settings has and is saved as you set it. Leave it untouched and nothing changes: Ask, lid off, computer use off. It is asked once; someone already set up is not asked.
