# Superagent 2.0.0-beta.55

**Restart when finished is the default, and project icons stay put.**

- **Restart when finished comes first.** When an update is ready while agents are working, the restart card's main button now waits for them to finish and then restarts. Restarting straight away, which stops their work, is the quieter choice beside it.
- **Project icons no longer blink out.** An icon started blank every time its row appeared and waited to be read again. The last icon is now shown at once, remembered across restarts, and refreshed quietly behind it.
