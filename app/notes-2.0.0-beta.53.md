# Superagent 2.0.0-beta.53

**The restart warning is easier to read.**

- **A card, not a crowded pill.** When an update is ready while agents are still working, the warning now reads top to bottom: what is still running, then each chat as its own tile, then the three choices together. A terminal command shows in a code font with its kind as a small tag, and hovering a tile offers to open that chat. "Restart anyway", the choice that stops work, comes last and in amber.
