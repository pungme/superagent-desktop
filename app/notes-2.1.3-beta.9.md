# Superagent 2.1.3-beta.9

**Claude Code stays up to date by itself.** The model picker is Claude Code's own list, so a new model (like Fable 5.2) only shows up once Claude Code is new enough to list it, and its own updater can fall behind: it had left one Mac two weeks old. Superagent now runs Claude Code's `claude update` about a minute and a half after it opens and every 12 hours after that. Chats already open keep the version they started with; a new chat gets the new list.

It is on by default. Turn it off, or check right now, in Settings → Agents → Claude Code → "Keep it up to date".
