# Superagent 2.1.3-beta.38

**Switching a chat back to an agent picks up where that agent left off.** Move a conversation from Claude to Codex and back, and Claude resumes its own thread and is told only what it missed, instead of starting over from a recap of everything. The same goes for switching agents from the phone.

**Turn off all simulators when you ask an agent to.** An agent asked to shut down every simulator used to be refused and could only tell you to open Terminal. It can now ask you in a dialog (Cancel is the default) and turn them all off if you say yes.

**A long step says what it is.** When an agent is in the middle of a long step, the chat says so, and messages you send during it say they are waiting, instead of looking stuck.
