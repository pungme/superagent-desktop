# Superagent 1.9.2-beta.16

- **Answering an older question.** Pick an option on a question from a few messages up and it goes with that question quoted, so the agent answers the right one instead of taking it for its latest message. For a typed answer, hover the message and use Reply.
- **The model menu is short again.** Claude Code now lists every version still available; the menu shows the current ones and keeps the rest behind "Older models…". Same on the phone.
- **A project's name comes first** in the sidebar: the branch chip and the ahead/behind counts make room for it, and hide when the sidebar is narrow.
