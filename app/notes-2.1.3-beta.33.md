# Superagent 2.1.3-beta.33

**The file editor saves by itself.** What you type is written to the file moments after you stop, and right away when you send the agent a message, click away, switch to View or close the file. The agent always works from what you see, so a forgotten ⌘S can no longer lose your edits. The Save button is gone; the status line says Saving… or Saved, and ⌘S still saves on the spot. If an agent changed the file since your last save, nothing is overwritten: the editor stops and asks which version to keep.
