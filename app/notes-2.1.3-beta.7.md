# Superagent 2.1.3-beta.7

**Your phone gets Save for later and Skills.** The Superagent iPhone app now shows the prompts you set aside with Save for later (the same list as here: save one on the Mac and it is on the phone, and the other way round), and Settings → Skills on the phone lists what each agent on the Mac can run, claude.ai skills included. This beta makes the Mac answer for them; the iPhone app's next update shows them.
