# Superagent 2.0.0-beta.41

**Right-click an image; ⌘K keeps the keyboard's pick.**

- **Right-click works in the app's own window.** An image in a conversation or in the picture viewer can be saved ("Save Image As…") or copied; a text field gets Cut, Copy, Paste and Select All; selected text gets Copy. The app window had no right-click menu at all before.
- **⌘K no longer lets a resting pointer steal the highlight.** The palette opens under wherever the pointer happens to be, and the row under it was taken for a hover, so the first result lost its highlight before you pressed a key. Now the keyboard has it until the pointer actually moves; from then on the pointer does, as in any menu.
