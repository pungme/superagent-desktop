# Superagent 2.0.0-beta.2

Polish for the dot, and everything from 1.9.8.

- **Follow-ups stay in the same conversation.** Ask again with an answer on screen and the agent knows what you were just talking about. Clear, or picking another project, starts a new conversation. An approval that is still waiting is no longer lost when you ask something else.
- **Arrow keys in the project picker.** Up and Down move through the list from the project in use; Enter picks it. The project in use is ticked.
- **Always readable.** The dot's panel is dark whatever the app's theme is; with the app in light mode, parts of an answer could be dark on dark.
- **It comes back if its screen is unplugged.** Left on a second monitor that has gone, the tile returns to the corner of the main screen.
- **A request that can't be sent says why**, and keeps what you typed.
- **From 1.9.8:** one agent to a conversation, a Stop that ends the process, and a log of why an agent stopped.
