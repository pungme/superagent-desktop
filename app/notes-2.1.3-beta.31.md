# Superagent 2.1.3-beta.31

**Chats go back to your preferred account.** When an account runs out, a chat moves to the next one in your order, and until now it stayed there. Now it moves back as soon as the account it left (or any account higher in your order) has allowance again: between messages, never in the middle of a reply. A chat you moved by hand stays where you put it.

**A much nicer file editor.** Markdown is coloured as you type, with bold headings and faded syntax marks, in a centred column that reads like a page. Code files are coloured too. Tab indents, Return continues a list, and a status line shows words, lines and whether it is saved.
