# Superagent 2.1.3-beta.21

**Computer use no longer stops because Passwords or 1Password is open.** Having a password manager open anywhere on the screen made computer use refuse every look ("Passwords is on this display…"), even while the agent worked in another app; it stopped 17 times that way. Now the password manager's windows are greyed out in the picture and the agent carries on: none of it is ever in a picture. It still stops when the password manager is the app in front, and for a macOS password prompt or the lock screen, which need you.
