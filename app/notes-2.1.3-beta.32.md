# Superagent 2.1.3-beta.32

**The file editor shows an agent's changes, and never saves over them.** A file open in Edit mode used to keep showing the old text after an agent changed it, and Save then wrote over the agent's work. Now the new text appears as soon as the agent finishes. If you have unsaved edits, they stay, and a bar lets you choose: use the new version or keep yours. Save also checks the file first, so it never overwrites a change it hasn't shown you.
