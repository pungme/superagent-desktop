# Superagent 2.0.0-beta.44

**Let it use any app, without the ask.**

- **Settings → Computer use → "Ask before the first time in each app".** On, as before: each app is put to you the first time a conversation works in it, with Always allow for the ones you trust. Turn it off and an agent may work in any app straight away. Password managers, Keychain, the lock screen, macOS password prompts, Superagent's own window and the apps on your own list stay out either way, and anything named Quit, Delete or Send is still asked about first.
