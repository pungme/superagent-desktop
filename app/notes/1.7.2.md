## Superagent 1.7.2

- **Snip can't trap you.** ⌘⇧S (snip) used to dim the window and then ignore Esc if the page had the keyboard — it looked like the app had frozen. Esc now always works, and both snip layers have a ✕ Cancel button.
- **Keep / Throw away / New chat explain themselves.** Hover a pill and it says what happens — Keep adds the chat's changes to the project as one change and closes the chat; Throw away deletes its branch and working copy for good.
- **It's "Superagent" now** — one word, everywhere you read it.
