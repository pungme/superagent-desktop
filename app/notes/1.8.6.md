# Superagent 1.8.6

- Typing in a long chat no longer jumps the transcript up on every keystroke, and is smoother overall.
- Messages sent from the phone can no longer be delivered twice — a retried send is accepted once, so the agent isn't asked to do the same thing again.
- The agent picker shows each backend's logo (Claude, OpenAI), in the menu and on the selected pill.
- Simulator and web mirror panes have a clear ✕ to close them.
- A worktree with no chat (e.g. a leftover PR checkout) can be removed with its own ✕.
- Hold Send to send a message after the agent finishes, instead of interrupting it.
- Simulator tapping no longer plays back a backlog of stale taps when it gets busy.
