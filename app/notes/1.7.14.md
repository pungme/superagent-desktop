## Superagent 1.7.14 — the first message cuts the branch, wherever it came from

**A conversation started on your phone now gets its own copy of the project.** The rule — cut a branch on the first message and name it from what you asked for — lived in the window, and the phone's messages never pass through it. So a chat sent from the phone ran in the project folder itself, beside whatever was already working there: two agents, one checkout, which is exactly what 1.7.12 set out to make impossible. The rule now lives in one place and both surfaces use it.

**Your phone can see the branches.** It listed conversations while the Mac listed branches, so a branch with no chat, or one whose chat was deleted, simply was not there. The phone now draws the same rows from the same git listing: the project row is the folder's own conversation, and the list beneath it holds the branches, each naming the conversation in it.

**The Mac's browser stops rearranging itself when the phone looks at it.** Opening a chat on the phone, with a page attached, left that page laid out at desktop width in the Mac's window. Taking a picture of a hidden pane means parking it in the window for a moment; nothing was taking it back out afterwards.

**Your phone can see the Simulator too** — the device's name, a picture about once a second, and taps that land on it.

**A file the agent hands you stays in the conversation**, on both surfaces: a card with its name and where it lives, which opens the file when you click it. And Files follows the conversation now, so a report written in a chat's own copy of the project appears in the tree beside it rather than in a folder nothing on screen pointed at.
