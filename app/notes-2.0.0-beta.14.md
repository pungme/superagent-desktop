# Superagent 2.0.0-beta.14

**By asking**

- **"Go back."** Superagent returns to the conversation you were looking at before; ask again to go further back.
- The dot now says what it is doing in plain words ("Looking for the chat", "Opening it", "Reading the controls") instead of tool names.

**Pictures**

- From the Images view, "show in chat" takes you to the message a picture came from and lights it for a moment.

**Computer use**

- A paired phone is told when an agent asks to use the Mac, without an Approve button that could not work: that yes is given at the Mac.
- For Codex chats, a command that would drive the mouse, keyboard or screen from the shell is declined whenever Codex asks before running it.
