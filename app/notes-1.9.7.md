# Superagent 1.9.7

- **Pictures in a reply show on the phone.** A screenshot the agent puts in its reply is usually saved outside the project folder, and the Mac only let the phone read files inside it, so the phone showed a grey label with the file's name instead of the picture. The Mac now sends the phone any picture that a reply in that conversation names, wherever it is saved. Nothing else outside the project can be read this way, and no new iPhone build is needed.
