# Superagent 2.0.0-beta.43

**The dot walks you through the Mac's permissions.**

- **Asked to use the Mac before macOS has allowed it, the agent guides you through it, from wherever you asked.** You are asked once ("Superagent needs Screen Recording and Accessibility — open System Settings?"); a yes brings up macOS's own prompts and opens System Settings at the right switch, and Superagent waits while you flip it, then carries on with what you asked. Before, the agent told you to find Settings → Computer use yourself and ask again.
- **A restart, offered when macOS needs one.** Screen Recording takes effect only once the app is opened again; if a picture still fails after you allowed it, you are offered a restart. The conversation is there when it is back.
