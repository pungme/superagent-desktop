# Superagent 2.0.0-beta.4

- **Stuck in the browser, the dot sends you there.** When the agent needs you to sign in, pass a captcha or enter a code, the dot says so and offers Open in Superagent. It used to offer Allow and Not now, which meant nothing for that.
- **The dot starts lighter.** Its window no longer loads the whole app's code to draw a tile.
