# Superagent 2.0.0-beta.5

**Computer use.** An agent can now use your Mac itself: see the screen and work the mouse and keyboard in any app, for what only an app's own window can do.

- **Off until you turn it on:** Settings → General → Computer use. It needs two macOS permissions, Screen Recording to see and Accessibility to act; Settings has a button for each and a **Check it works** that really tries.
- **It asks first.** The first time a conversation wants to use your Mac it asks, and asks again after ten minutes idle.
- **⌥Esc stops it** from whatever app is in front. While an agent has control, the dot turns blue and says "Using your Mac", with a Stop button.
- **What it can do:** take a screenshot, click, double-click, right-click, drag, scroll, type, press shortcuts and open apps, looking at the screen again after each step.
- **What it is told not to do:** type passwords, card numbers or one-time codes, approve payments or permission dialogs, or do anything that cannot be undone without saying so first. It reaches for a command, a file or the browser first when those can do the job.
- **Ask from the dot.** Pick Computer in the dot and say what you want done in an app.
