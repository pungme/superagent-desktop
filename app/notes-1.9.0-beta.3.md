# Superagent 1.9.0-beta.3

Beta channel.

- Right-click a project → **New Chat** works from anywhere. If the Computer, Chats, Dashboard, Skills, Routines or Settings page was on screen, the chat was created and switched to underneath it, so the menu item looked dead. The same was true of opening a branch, keeping a worktree, a new browser tab, a project the agent had just cloned, and the "shall the agent sort it out" prompt — six ways in, all of which now leave whatever is covering the workspace instead of quietly changing something you cannot see.
