# Superagent 2.1.0-beta.27

**Your claude.ai integrations work in Superagent.** Connectors such as Instantly, Superhuman Mail, Attio and Gmail now show under each Claude account in Settings → Agents, as Connected or Connect. Connect signs you in to that service in a window of Superagent's; no terminal, no /mcp. If a chat needs a connector that is not connected, a card offers to connect it right there.

**Extra Claude accounts sign in fully, inside Superagent.** "Add account…" opens claude.ai in an app window, you sign in, and the account appears with its name and plan. Before, extra accounts were added as tokens, which Anthropic limits to chatting: no claude.ai connectors and no Claude in Chrome. An account added that way now says so and offers "Sign in fully", which keeps its chats. If you sign in to claude.ai with Google, Google refuses windows inside apps, so that one step finishes in your browser and Superagent carries on by itself.

**Choose the default account.** "Make default" sets which account new chats start on, per agent; the usage menu and the Account menu mark it. If it has run out, new chats start on the next account with allowance.
