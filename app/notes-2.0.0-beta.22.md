# Superagent 2.0.0-beta.22

**Quieter loops, and logs you can clear.**

- **A loop's rounds look like a loop.** Each round used to arrive as your own message with a paragraph of instructions for the agent on the end. It is a small outlined note now, marked Loop, with what you asked and nothing else.
- **An answer says what it answers.** Picking an option after you have written something else, or while the agent is already at work, sends the question along with it. It used to go bare, and read as an answer to whatever came last.
- **Logs can be cleared** in Settings → Advanced → Storage. They are the app's own notes for finding a fault, nothing of yours.
- **A memory snapshot no longer sits on the disk for good.** One taken during a crash could be several gigabytes; only one is kept, and it is removed after a week.
