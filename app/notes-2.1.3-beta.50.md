# Superagent 2.1.3-beta.50

**Conductor: connectors, and the Sessions panel follows you.** The Sessions tab draws Main's trunk with a curved branch into each session (pulsing blue while a session works, dashed amber when it needs you, dashed grey when it is closed or not connected). Opening a session from the tab keeps the tab open beside it, so going Main → #101 → #102 no longer means opening Sessions again each time.
