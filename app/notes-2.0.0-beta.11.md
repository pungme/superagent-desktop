# Superagent 2.0.0-beta.11

**The dot is a remote control for Superagent itself.** Ask for things instead of clicking for them, typed or spoken (⌃⌥ V), from any app:

- **"Go to the wepush chat about e2e testing."** It finds the conversation from how you describe it (its topic, its project, something said in it) and takes you there. When several fit equally, it asks which.
- **"What's running?"** The conversations whose agents are working, and the ones you used last.
- **"Start a chat in the portal to fix the header."** A new conversation in that project, with the job handed to its agent.
- **"Tell the api chat to rerun the tests."** A message into another conversation. You are asked to allow each one.
- **"Stop it", "rename this to…", "pin it", "open settings".**

It works in any chat, not only the dot.
