# Superagent 1.9.2-beta.22

- **A cleared chat no longer breaks on the phone.** After "Clear chat…" on the Mac, the phone kept showing the old conversation and messages sent from it disappeared. The Mac now tells the phone to start that conversation over. The phone needs the matching iOS update for the full fix.
- **No more false "The agent stopped".** That notice was appearing under every finished reply a few minutes later. It now shows only when the agent really died.
- **Fold and unfold a foldable simulator.** A fold button in the simulator pane for iPhone Duo, and the agent can do it itself.
- **Pictures in replies.** When the agent points at an image file on disk, it shows inline in the chat.
