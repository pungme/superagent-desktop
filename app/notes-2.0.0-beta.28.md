# Superagent 2.0.0-beta.28

**Go to a project from the dot.**

- **The dot's project list goes places.** Each project has a ↗ that opens it in Superagent's window, and ⌘↩ does the same from the keyboard: find it, press it, you are there. ↩ alone still picks the project to ask in. It works with the window closed too.
- The tour's page on the dot says what it is for: the best agent is the one that disappears.
