# Superagent 2.0.0-beta.37

**The dot stays put, follows your screen, and shows up in screenshots.**

- **The dot is in your own screenshots.** It was kept out of every screen capture so that an agent using the Mac would see what is under it; that also made it impossible to screenshot. Now it steps out only for the moment an agent takes its picture.
- **It stays in its corner.** No more dragging the tile about: bottom right, always. One left somewhere else by an earlier version comes home.
- **With two screens, it is on the one you are on.** It follows the pointer to the other screen's corner (not while its panel is open), instead of waiting on the main one.
- **Images moved to the top right of the chat.** The button for every picture in a conversation sits beside New chat, where it is about the chat, rather than among the composer's settings.
