# Superagent 2.0.0-beta.3

More for the dot.

- **Choose the shortcut.** Settings → General → The dot has a Shortcut choice: ⌥ Space, ⌃ Space, ⌥⌘ Space, ⌃⌥ Space, ⌥⇧ Space, or none. If another app already has the one you picked, Settings says so instead of leaving a shortcut that does nothing. The tile's tooltip shows the one in use.
- **The agent's questions are buttons.** When the agent asks you to choose, the dot shows the options to click, as the chat does, instead of a block of code. Several answers can be ticked and sent together.
