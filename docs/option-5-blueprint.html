Fig. 04 — Dual viewport

One page, seen twice.

One click shows the same page in a desktop card and an iPhone frame — same session, both live. Scroll one and the other follows; every change lands in both at once, so responsive bugs turn up before you ship them.

[K]Desktop card — 1440 × 900
[L]Phone frame — 390 × 844
[M]Shared session — one login, both views

Appendix A — tolerances

The small things, done properly.

A-01Survives restartsPanes, open files, active chat — exactly where you left them, even through updates.
A-02Never steals focusAgents finish quietly in the background. The window comes forward only when you ask.
A-03Interject mid-turnType while the agent works and it sees your message before it finishes — like the terminal.
A-04Context gaugeEvery conversation shows how much of the context window it has used.
A-05Useful notificationsDone, or has a question — with a summary of the agent's actual last reply.
A-06Updates itselfSigned, notarized, delivered in the background. Restart when it suits you.
