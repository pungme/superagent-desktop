Every agentすべてのエージェント

Claude, Codex, Gemini. Never stuck.

Pick Claude Code, Codex or Antigravity (Gemini) for each chat. When an account runs out, Superagent moves the chat to your next one and keeps going.

Add more than one account per agent, and turn on Automatic under Settings → Agents → When an account hits its limit; otherwise the chat asks first, with a button to switch. If only one Claude model runs out (Fable’s weekly limit, say), the chat steps down to the next model and goes back once it can. A chat never changes agent on its own; you pick that.

Questionsよくある質問

Good questions.

Is Superagent a GUI for Claude Code?

Yes. It runs the real Claude Code CLI on your Mac and gives it a window: chats per project, a built-in browser, an iOS Simulator and an iPhone app. It does the same for OpenAI Codex and Google Antigravity, and you can switch agent per chat.

Do I need an API key?

No. It uses the agent you are already signed in to, on your Claude Pro or Max, ChatGPT Plus or Pro, or Google AI plan.

Is Superagent free?

Yes, free forever. No plan, no trial, no card, no account. It is open source under the MIT license.

What’s the catch?

There isn’t one. You already pay for the AI: Superagent runs on your own Claude, ChatGPT or Google plan, so there are no tokens of ours to bill you for. It has no servers of ours either; everything runs on your Mac, and the small encrypted relay for the phone costs next to nothing and you can host your own. It is open source under the MIT license, with no account, no tracking and no ads. All it needs is a Mac with Apple Silicon and a plan for at least one of the agents.

What happens when I hit my Claude limit?

Superagent moves the chat to your next Claude account that still has allowance, and the conversation carries on where it was. With Automatic on (Settings, Agents, When an account hits its limit) it switches by itself and says so; otherwise a card asks first, with a button to switch. If only one model's limit runs out, such as Fable's weekly limit, the chat steps down to the next model and goes back once it can. It never moves a chat from Claude to Codex or Antigravity on its own; you choose the agent per chat.

Can I run several Claude Code or Codex sessions at once?

Yes. Each chat can work in its own git worktree on its own branch, so parallel agents don't step on each other, and split view shows up to eight chats in one window.

Can the agent test my website in a browser?

Yes. It drives a real browser next to the chat: it opens pages, clicks, types, takes screenshots and checks the page at phone size, on the sites you are already signed in to.

Can I use it from my iPhone or iPad?

Yes. The iPhone and iPad app follows your chats, end-to-end encrypted, so you can answer the agent and approve what it asks from anywhere.

Does my code leave my Mac?

No. Everything runs locally. The only traffic is your agent's own connection to its provider, update checks, and an encrypted relay if you pair a phone.

Does Superagent support Claude Code skills?

Yes. Open Skills from the View menu or ⌘K to see the skills and commands the chat’s agent can run, marked project or global. “Save last session as a skill” asks the agent to write the file for you: a Claude Code skill, a Codex prompt or an Antigravity skill. With none yet, it offers starter skills.

Can I send part of the screen to the agent?

Yes. Press ⌘⇧S, or the scissors on the browser or the simulator, and drag a box over the page or the phone screen. The crop lands in your message at full resolution.

Can the agent read and send my email?

Yes, once you connect Apple Mail in Settings, Connections. The agent can then search and read your mail and write drafts. It sends nothing by itself: each email is shown to you first, with its recipients, subject and attachments, and goes only when you approve it. macOS asks for permission the first time.

Can the agent keep working with my MacBook lid closed?

Yes. Turn on “Keep working with the lid closed” in Settings, General, Power. It is off by default, macOS asks for your password once, and your Mac stays awake while Superagent is open. On battery you choose the level under which it is let sleep, 20% unless you change it.

Does it work on Windows or Linux?

Not yet. Superagent is a Mac app for Apple Silicon.
