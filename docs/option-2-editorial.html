Issue nº 1 · The desktop agent

A home for your agent.

SuperAgent is a free, open-source Mac app that gives Claude Code a place to live — a real browser it drives, an iPhone in the window, and chats that survive restarts. It opens pages, tests what it builds, and shows you, right next to the conversation.

Six chapters

One window. Watch it morph.

The same app window, retold six ways as you read. Keep scrolling — the frame on the right follows along.

01
The sidebar

Tabs up top, chats below.

Plain browser tabs at the top of the sidebar — browse first, summon the agent when you need it. Conversations live underneath, unread dots and all, exactly where you left them.

02
Worktree chats

Its own branch, off to the side.

Start a chat on its own git worktree. The agent commits away on an isolated branch while your checkout stays clean — merge when you like what you see.

03
The simulator

An iPhone in the window.

An iOS Simulator streamed inside the app from its own framebuffer — the real device, live, tap and type included. Nothing to grant, nothing to install.

04
Two live views

Desktop & phone at once.

One click shows the same page in a desktop card and an iPhone frame — same session, both live. Scroll one and watch the other keep pace.

05
Automation

It drives the browser itself.

Ask for a page and it opens beside the conversation. The agent reads it, clicks around, fills the form, and screenshots the result — you watch it happen.

06
The finale

The computer inside SuperAgent.

A desk, not a slot: the page you're on, the simulator, a board Claude keeps, and a dashboard of your week — side by side on one surface, over a Monet you can switch off.

Appendix

The small things, done properly.

A·1Survives restartsPanes, open files, active chat — exactly where you left them, even through updates.
A·2Never steals focusAgents finish quietly in the background. The window comes forward only when you ask.
A·3Interject mid-turnType while the agent works and it sees your message before it finishes — like the terminal.
A·4Context gaugeEvery conversation shows how much of the context window it has used.
A·5Useful notificationsDone or has a question — with a summary of the agent's actual last reply.
A·6Updates itselfSigned, notarized, delivered in the background. Restart when it suits you.
