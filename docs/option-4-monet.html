VII. Open & local

Open source. No server.

An agent with a browser is an agent with your logins. So you should be able to see where it runs and read exactly what it does.

◇

Open source, end to end.

Not a wrapper with a peek at the source. The whole app is on GitHub under MIT.

  • ✓Read how it touches your browser. The part that matters most is the part you can audit.
  • ✓Build it yourself. Clone it, change it, ship your own. MIT means MIT.
  • ✓Signed and notarized by Apple, so the build you download is the one that was published.
  • ✓Issues in the open. Bugs, roadmap and arguments all happen in public.
⌂

It never phones home.

There is no SuperAgent server. There is nowhere for your work to go but your own disk.

  • ✓Your chats, code and pages stay local. Nothing is uploaded, because there is nothing to upload it to.
  • ✓Your own Claude subscription. The agent talks to Anthropic directly, with no proxy of ours in between and no second bill.
  • ✓No account, no analytics, no tracking. There is no sign-up screen and no telemetry SDK in the build.
  • ✓Your logins stay yours. Browser sessions live in a profile on your Mac, the same as any browser.

It's all public. read the source.
