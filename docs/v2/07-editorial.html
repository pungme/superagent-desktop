A Mac app for Claude Code

Your agent writes the code.
Where does it work?

SuperAgent gives it a browser it can drive, an iPhone it can install onto, and a desk to keep the work on.

Free and open source · Apple Silicon · runs on your own subscription

The part you usually take on trust is the part that happens off-screen. An agent tells you it opened the page, that the layout is fixed, that it checked on a phone. You believe it, or you check yourself. SuperAgent removes the choice: the browser it drives is the one on your screen, signed into the sites you are already signed into, and you watch it work.

The chat lives beside it. Ask for a change and the page reloads in the same window — your dev server runs in a strip above the work, so the loop is ask, watch, ask again, without ever alt-tabbing to find out whether it worked.

Not a hidden browser it describes to you afterwards. The one on your screen, with your logged-in session — and you can take the mouse back at any moment.

Everything in its place

Plain browser tabs sit at the top of the sidebar: browse first, summon the agent when you need it. Below them, projects group the way you actually think about them, each conversation nested underneath, with a spinner while the agent works, a dot when it needs you, and the git branch where you would expect it.

The bigger things

A real iOS Simulator streamed inside the window from its own framebuffer — tap it, type into it; it is the device, not a picture of one. A board the agent keeps, moving cards from doing to done as the work lands. Worktree chats, so a conversation runs on its own branch while your checkout stays clean. Routines that keep watching a page on a timer and tell you what changed.

And then it goes quiet

The rule the whole app is built around: it never steals your focus. Agents finish in the background and send a notification with a summary of what they actually said. The window comes forward when you ask it to, and not before.
