01Build it and watch it, side by side

The chat sits next to a real browser. Ask for a change and watch the page update in the same window — no alt-tabbing to find out whether it worked. Point it at a local dev server or any live site.

02An agent that can use the browser

Claude drives that same browser: open a page, click, type, read it back. Not a hidden headless browser it describes to you second-hand — the one on your screen, with the sessions you are already logged into. You watch it work, and you can take over at any time.

03Everything in its place

Plain browser tabs sit at the top of the sidebar — browse first, summon the agent when you need it. Below them, projects group the way you think about them, with each conversation nested underneath. A spinner while the agent works, a dot when it needs you, the git branch where you would expect it.

04The bigger things

  • Desktop & phone at onceThe same page in a desktop card and an iPhone frame — same session, both live.
  • An iPhone in the windowAn iOS Simulator streamed inside the app from its own framebuffer. Tap it, type into it.
  • A board it keepsBacklog, next, doing, done — per project, and Claude moves the cards as it works.
  • Worktree chatsA conversation on its own git branch, in its own worktree. Your checkout stays clean.
  • Routines“Check this site every hour,” in plain language, on a timer.
  • Dev server stripIt starts your dev server and iterates while you watch the page change.

05The small things

  • Never steals focusAgents finish quietly in the background. The window comes forward only when you ask.
  • Survives restartsPanes, open files, the active chat — even through an update.
  • Light on memorySessions start on your first message and wind down when they go idle.
  • Interject mid-turnType while it works and it sees your message before it finishes.
  • Talk instead of typingHold ⌥Space and speak. Transcribed on your Mac, never sent anywhere.
  • Notifications that say somethingDone, or has a question — with a summary of what it actually said.
