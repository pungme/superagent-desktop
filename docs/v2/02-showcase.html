Build it and watch it, side by side.

The chat sits next to a real browser. Ask for a change and watch the page update in the same window — no alt-tabbing to find out whether it worked. Point it at a local dev server or any live site, and the dev server runs in a strip above the work.

It uses the browser you are already logged into.

Claude opens a page, clicks, types, reads it back. Not a hidden headless browser it describes to you afterwards — the one on your screen, with your sessions. You watch it work, and you can take the mouse back at any moment.

And everything else it needs.

An iPhone in the window

A real iOS Simulator streamed inside the app from its own framebuffer — tap it, type into it, at the rate it renders.

A board it keeps

Backlog, next, doing, done. Claude moves the cards as the work lands, and each one remembers the conversation that raised it.

Worktree chats

A conversation on its own git branch, in its own worktree — the agent works while your checkout stays untouched.

Routines

“Check this page every hour,” in plain language, on a timer — and it tells you what changed.

Files and PDFs

Click any file to read it beside the tree. Drag files into the chat and annotate PDFs in place.

Never steals focus

It finishes quietly in the background and sends a notification. The window comes forward only when you ask.

It runs on your Mac, on your subscription.
