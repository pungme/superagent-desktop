The screen it gets
A real browser

It navigates, clicks, types and reads back — in the browser on your screen, with the sessions you are already signed into.

Desktop & phone at once

One click shows the same live page in a desktop card and an iPhone frame. Same session, both live.

An iPhone in the window

A real iOS Simulator streamed from its own framebuffer. Tap it, type into it. Apple’s own window stays shut.

A desk, not a slot

Page and simulator sit side by side on one surface, arranged the way you left them.

The work it keeps
A board it keeps

Backlog, next, doing, done — per project. Claude moves the cards as it works, while you watch.

Worktree chats

A chat on its own git branch and directory. The agent works; your checkout never moves.

Files & PDFs

Click any file to read it beside the tree. Drag files into the chat, annotate PDFs in place.

Dev server strip

It starts your dev server and iterates while you watch the page change, one click away.

Routines

“Check this site every hour,” in plain language, on a timer — with what changed.

Dashboard

Turns per day, tasks done, a streak, and which projects got your time. Computed locally.

Many chats per project

They name themselves after what the conversation turned out to be about.

Context gauge

Every conversation shows how much of the context window it has used.

How it behaves
Never steals focus

The rule the whole app is built around. It asks with a notification and comes forward only when you say so.

Survives restarts

Panes, open files, the active chat — exactly where you left them, even through an update.

Light on memory

Sessions start on your first message and wind down when idle. Nothing runs for the sake of running.

Interject mid-turn

Type while it works and it sees your message before it finishes — like the terminal.

Talk instead of typing

Hold ⌥Space and speak. Transcribed on your own Mac; your voice never leaves it.

Quiet by default

A burst of activity folds into one line you can open, instead of a wall of noise.

Useful notifications

Done, or has a question — with a summary of what it actually said.

Updates itself

Signed, notarized, delivered in the background. Restart when it suits you.

Free · open source · Apple Silicon · runs locally on your own Claude subscription.
