Claude Code, with a screen.
A browser, a phone and a desk it can actually use.

Your agent already writes the code. SuperAgent gives it somewhere to work: a persistent chat per project, a real browser it drives on the sites you are already logged into, files beside the chat, and routines that keep running on a timer. Local, on your own Claude subscription, open source end to end.

↓ SuperAgent.dmg git clone

what it does

browser      navigate · click · type · read back      ← your logged-in session
simulator    boot · install · launch · tap · type      ← streamed framebuffer
files        read · edit · annotate PDFs               ← beside the tree
board        backlog → next → doing → done             ← it moves the cards
routines     "check this page every hour"              ← plain language, on a timer
worktree     a chat on its own branch                  ← your checkout stays clean

flags you would have wanted

--never-steal-focuson, always. It notifies; it does not come forward. --survives-restartpanes, open files, the active chat — even through updates. --idle-shutdownsessions start on your first message and wind down when quiet. --interjecttype mid-turn and it sees you before it finishes. --voicehold ⌥Space; transcribed on your own Mac, never uploaded. --quieta burst of tool calls folds into one line you can open. --local-onlyno middleman server. Your keys, your machine, your subscription.
