1Plain browser tabs

Browse first; summon the agent into the page when you need it.

2Projects and their chats

Grouped the way you think about them, branch chip included. A spinner while it works, a dot when it needs you.

3The live page

A real browser it drives — navigate, click, type, read back — using the session you are already signed into.

4Phone frame / simulator

The same page at phone width, or a real iOS Simulator streamed from its own framebuffer.

5Folded tool burst

“3 steps · 1 edit”. Open it if you care; ignore it if you do not.

6The answer

What it found, in words, next to the thing it found it in.

7Composer

Type, or hold ⌥Space and speak — transcribed on this machine. Interject while it is still working.

8Routines and skills

“Check this page every hour,” in plain language, on a timer.

Capabilities

Browser control

Open, click, type, read back. Your logged-in session, on screen, reversible at any moment.

iOS Simulator

Boot, install, launch, tap and type — streamed inside the window. No permission to grant.

Files and PDFs

Read anything beside the tree; annotate PDFs in place and it reads the marks.

Board

Backlog → next → doing → done, per project, moved by the agent as work lands.

Worktree chats

An isolated branch and directory per conversation. The working tree does not move.

Dev server strip

Starts your server, shows the port, reloads the page while you watch.

Behaviour

FocusNever raises its own window. Notifies with a summary of the agent's actual reply; comes forward only on request.
PersistencePanes, open files and the active chat survive quit, relaunch and update.
MemorySessions begin on your first message and wind down when idle. Agents run only while conversations do.
InterruptionType mid-turn; the agent sees it before it finishes.
NetworkTalks to Anthropic on your own subscription. No middleman server, no telemetry.
AppearanceLight and dark, following the system.
UpdatesSigned, notarized, delivered in the background. Restart when it suits you.
