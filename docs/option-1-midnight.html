Details

The small things, done properly.

Survives restarts Panes, open files, active chat — exactly where you left them, even through updates.
Never steals focus Agents finish quietly in the background. The window comes forward only when you ask.
Interject mid-turn Type while the agent works and it sees your message before it finishes — like the terminal.
Context gauge Every conversation shows how much of the context window it has used.
Useful notifications Done or has a question — with a summary of the agent's actual last reply.
Updates itself Signed, notarized, delivered in the background. Restart when it suits you.
